# 📱 4º Semestre: Mundo Mobile, Automação & Notificações

**Status: Planejado** 📅

## 🎯 Objetivo
Expandir o ecossistema do **Active Age** para os dispositivos móveis através de aplicativo nativo multiplataforma (React Native) focado no paciente idoso e cuidadores, automatizar o ciclo de entrega de software com esteiras de CI/CD e introduzir o primeiro microsserviço assíncrono de mensageria para notificações clínicas e recuperação de senha.

## 🛠️ Disciplinas Integradas (Fatec Diadema - DSM)
* **Programação para Dispositivos Móveis I:** Desenvolvimento de aplicativo mobile com React Native / Expo focado em acessibilidade para idosos (leitura de tela, botões gigantes e comandos de emergência).
* **Integração e Entrega Contínua (CI/CD / DevOps):** Pipelines automatizadas com GitHub Actions para testes e deploy contínuo em múltiplos ambientes.
* **Arquitetura Orientada a Serviços:** Implementação do **Microsserviço de Mensageria & Notificações** (Worker assíncrono com filas RabbitMQ/Redis para e-mail, WhatsApp e lembretes de consultas).
* **Segurança da Informação:** Emissão de receitas e atestados em PDF com assinatura digital no padrão ICP-Brasil.

## 📦 Entregas Previstas
1. **Aplicativo Mobile Active Age (React Native):** Visão simplificada para o idoso (consultas do dia, botão de emergência SOS e receitas médicas salvas).
2. **Microsserviço de Notificações:** Envio desacoplado de e-mails transacionais (recuperação de senha), SMS e mensagens de WhatsApp para lembretes de teleconsulta.
3. **Pipeline de CI/CD:** Automação de testes integrados e deploy no GitHub Actions.
