# 💻 2º Semestre: Motor Relacional e Lógica Orientada a Objetos

**Status:** Em Desenvolvimento 🚧

## 🎯 Objetivo
Dar vida ao Active Age construindo o Back-End orientado a objetos e integrando-o a um banco de dados relacional. O foco é refazer o fluxo de Login real e construir um CRUD completo para o sistema de agendamento, além de conectar com as interfaces estáticas do 1º Semestre.

## 🛠️ Tecnologias Adotadas
* **Back-End:** TypeScript (Node.js) aplicando Arquitetura MVC e POO.
* **Banco de Dados:** MySQL.
* **Front-End:** Reutilização e integração das páginas web criadas no 1º Semestre.

## 🚀 Escopo de Entregas
* **Login e Autenticação:** Refatoração do login utilizando validação real de dados no MySQL.
* **CRUD de Agendamento:** Funcionalidade completa para o paciente listar horários e agendar consultas.
* **Seed de Dados (Homenagem):** Banco de dados populado automaticamente com médicos baseados em grandes lendas da tecnologia (Ex: Dra. Ada Lovelace, Dr. Alan Turing) para testes do sistema.
* **Jornada do Paciente:** Após o agendamento, redirecionamento do usuário para uma página simulada de videochamada (preparação para o WebRTC do 6º semestre).
